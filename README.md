INSTALAÇÃO DA EXTENSÃO NO GOOGLE CHROME / EDGE
=============================================

1. Extraia o arquivo ZIP para uma pasta no seu computador
<img width="1837" height="600" alt="image" src="https://github.com/user-attachments/assets/08a7c5fd-46aa-474e-8d8d-91302eb57837" />

2. Abra o navegador e acesse:
   - Chrome: chrome://extensions
   - Edge:   edge://extensions
     
<img width="2557" height="932" alt="image" src="https://github.com/user-attachments/assets/adcc6f01-00a5-4c90-aef1-a5d96cc973da" />

3. Ative o "Modo do desenvolvedor" (Developer mode) no canto superior direito e clique em "Carregar sem compactação" (Load unpacked) e selecione a pasta extraída

<img width="2557" height="537" alt="print-enable-plugin" src="https://github.com/user-attachments/assets/92569708-8167-4f59-8445-f7331f4a9728" />

4. Instalação concluída.

COMO USAR
=========
1. Acesse https://brasilparticipativo.presidencia.gov.br/processes/listaestimacao/f/6223/
   e faça login com sua conta Gov.br.

3. O painel "Automação Consulta IBAMA" aparecerá automaticamente no canto inferior direito
   selecione seu arquivo com os 88 comentários técnicos.
   
   <img width="2532" height="1596" alt="Screenshot 2026-11-19 004219" src="https://github.com/user-attachments/assets/47d8896e-1bd2-4d5f-87cd-3b40e9193980" />
   
5. Desmarque "Modo Simulação" quando estiver pronto para enviar e clique em "Iniciar".
